### Contexte du projet

L'application est un CRM simplifié avec un back en java et un front Angular. Le projet consiste à ajouter une pipeline CI / CD

### Objectifs de l'industrialisation

L'ajout d'une pipeline CI / CD permettra de :

- Garantir la qualité du code ( exécution systématique des Tests automatisés )
- Minimiser les erreurs de humaines ( automatisation )
